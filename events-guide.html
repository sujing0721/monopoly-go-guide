Events Guide: Read the Calendar, Then the Rewards

New limited-time events show up almost daily, each with its own rhythm. The players who win them aren't the ones with the most dice — they're the ones who know which event is worth a bank and how to walk into it ready.

How the Event Calendar Actually Works

Timing

The rotation runs on an ongoing weekly cycle — there isn't a fixed monthly reset. Event types recur on roughly a 5–7 day cycle, but they overlap and stagger, so there's almost always something live.

Don't memorise dates — learn rhythm

Exact schedules shift every cycle. What stays constant is the pattern: big events tend to cluster near the start of a period, quiet gaps follow, and multipliers usually attach to the flagship event of the week.

Bank ahead of the flagship

Once you spot the week's headline event, start stockpiling 2–3 days early. Dice released into a boosted window are worth double or triple the same dice rolled casually — the core rule from our dice strategy guide.

Always check before spending

One glance at the calendar before any spending session: if a bigger event opens within 48 hours, today is a no-spend day, full stop.

Exact rewards: in-app only

Reward tiers and timings change between runs of the same event. Treat any third-party table (including this page) as structure, not specifics — confirm in-app before committing your bank.

The Six Recurring Event Types

Event Types

Nearly everything the game ships fits one of these six shapes. Learn what each one rewards and you can evaluate a brand-new event in seconds.

Updated — Oct 10, 2026
Racing

Tycoon Racers

A race-style event against other players — fast-paced, best played in one focused burst. Save your dice for a few days before it opens so you can push through all stages in a single session.

Co-op

Partner Event

Team up with a friend to push a shared score. Your partner's activity matters as much as yours, so line up an active partner in advance — a quiet partner can cost you the full reward.

Ladder

Prize Drop

Bank points to climb a reward ladder. Later tiers pay off disproportionately more, so plan how many dice waves you'll need to hit your target tier before the timer runs out.

Mini-game

Peg-E

A pachinko-style mini-game that stacks odds with token drops. Good for spending spare dice during quiet stretches, but don't burn your event reserve on it unless you're already set for the main events.

Tournament

Timed Tournament

Short head-to-head scoring against random opponents. Rewards are strong but dice burn fast — only join if you have enough saved to finish, otherwise the early rounds return very little.

Milestone

Milestone Rewards

Unlocks rewards based on cumulative progress across normal play — no extra dice needed. Steady daily play pays off here even without chasing first place, making it the most reliable event type.

Which Events Deserve Your Dice Bank

Decisions

You can't max every event — the calendar overlaps on purpose. Score each live event against these four questions and the decision makes itself.

Q1

Is there a multiplier attached?

The same dice inside a 2x window return double the progress. A mediocre event with a strong multiplier usually beats a headline event without one.

Q2

Can my bank realistically reach a good tier?

Half-finishing a ladder event returns little. If your reserve can't clear a meaningful tier, shift the dice to a build push or a smaller event instead.

Q3

Does it need another person?

Co-op events hinge on a partner's activity. Only commit a big bank once you've locked in an active partner — otherwise your investment is hostage to someone else's logins.

Q4

Are the rewards things I actually lack?

Events pay cash, dice, sticker packs, and tokens in different mixes. A dice-heavy event is a better bank destination when your cash flow is already fine — and vice versa.

💡 The reliable floor: when in doubt, put the bank into whichever event feeds your sticker albums. Album completions pay dice back and move the long-term economy forward regardless of the week's meta.
